Xenosaga Episode I — Story Mode

A free, open-source difficulty change for the USA PlayStation 2 game. Fan project. Not made by or affiliated with Monolith Soft, Namco, or Bandai Namco. Made with Grok by xAI. MIT license.

Download the latest release

Install

  1. Close PCSX2.
  2. Open the zip and drag the patches folder onto your PCSX2 folder, into the same place as the patches folder that is already there.
  3. Replace the file when asked, then start the game.

That folder is the one Settings → Folders calls the Patches directory.

Linux, and the AppImage:  ~/.config/PCSX2/
Windows:                   Documents/PCSX2/
Flatpak:                   ~/.var/app/net.pcsx2.PCSX2/config/PCSX2/

Nothing else needs to be installed.

Always on

There is no cheat box. The patch is on every launch, and it is still on after you quit, while Enable Patches stays on. That setting is the default.

The zip installs Story Mode. Easy Mode is optional/easy-mode/. Use that file instead of the Story Mode file, not beside it. Healing and EP costs stay the same. A hit still does at least 1.

Remove it

Delete SLUS-20469_6D1276AB.pnach from the PCSX2 patches folder.

USA disc only. Serial SLUS-20469, CRC 6D1276AB. Source and releases: github.com/dunjeon/XenosagaEpisodeI-StoryMode
